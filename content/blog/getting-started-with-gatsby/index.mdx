Gatsby is a helpful way to build fast React websites with pages, data, and
images organized in one project. Starting with a small personal website makes it
easier to understand the basics without adding too many tools at once.

In this project, I am learning how Gatsby pages work, how reusable components
keep layouts clean, and how local content can become part of the site through
GraphQL.

My goal is to keep the project simple while gradually adding real features like
a blog and article pages.
