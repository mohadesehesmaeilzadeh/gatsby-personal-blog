React helped me understand how modern interfaces can be built from small,
reusable pieces. At first, concepts like components, props, and state felt new,
but they became easier once I practiced with simple projects.

What I like most about React is how it encourages clear thinking. Each component
has one job, and the page becomes easier to improve when the structure is simple.

I am still learning, but every project gives me a better understanding of how to
build responsive and user-friendly interfaces.
